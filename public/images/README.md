## 교체하는 방법

1. Figma에서 해당 노드 선택 → 우측 `내보내기` → 배율 지정(히어로 1x, 아이콘 2x) → `PNG`
2. 받은 PNG를 WebP로 변환하고 위 이름으로 이 폴더에 넣습니다.

```bash
node -e 'require("sharp")(process.argv[1]).webp({quality:84}).toFile(process.argv[2])' 입력.png 출력.webp
```

## 주의

- **히어로는 시안의 크롭을 쓰지 않습니다.** 시안 `Rectangle 14`(1920×757)는 세로 포스터를
  얇은 띠로 잘라 쓰는데, 그러면 헤드라인 `이 뮤지컬은 무대에 올라갈 수 있을까요?`의
  윗줄이 잘려 나갑니다. 포스터에서 글자가 차지하는 세로 범위가 70%를 넘어 2.5:1 띠에는
  구조적으로 들어가지 않습니다.
  그래서 자르지 않고 포스터 전체를 얹고, 히어로 배경색을 포스터 노랑(`#AE9B22`)으로 깔아
  가장자리가 이어지게 했습니다 — `app/(site)/page.tsx` 참고.
- **검정 20% 오버레이가 이미지에 구워져 있습니다.** 코드에서 또 얹으면 이중으로 어두워집니다.
- 배경색은 **브라우저가 이 webp에서 실제로 디코딩하는 값**을 써야 합니다.
  원본 PNG를 이미지 라이브러리로 재면 다른 값이 나옵니다(색 프로파일 처리 차이).
  이미지를 교체하면 배경색도 다시 뽑아 맞춰야 이음매가 안 보입니다.
- **아이콘 5개는 원본 크기가 제각각입니다**(181×160 ~ 139×122, Figma 코멘트 #3 미해결).
  코드에서 고정 박스 + `background-size: contain`으로 흡수하므로 깨지지는 않습니다.
  디자이너가 크기를 통일해 주면 그대로 교체만 하면 됩니다.
- 히어로는 최종본 여부가 확인되지 않았습니다(코멘트 #4).

## 이미 열려 있던 질문에 대한 답이 된 것

### 응원 게시판 쪽지 배치 규칙 — #43 (dladmsgp0311)

> 정사각형 악보와 직사각형 악보가 순서대로 배열
> 맨 왼쪽 상단 이름, 가운데 내용, 왼쪽 하단 메시지 창, 오른쪽 아래 날짜
> 노랑색 테이프 패턴은 77*36
> 노랑색 테이프 각도는 8도와 -8도를 번갈아 가면서

테이프 `77×36`은 실측값과 정확히 일치합니다. "수작업 배치라 랜덤 규칙이 필요하다"고
적어뒀던 부분의 답입니다. **랜덤이 아니라 8° / −8° 교대**이고, 악보 배경도
정사각형·직사각형을 번갈아 씁니다.

### 인물 카드 구성 — #37, #32 (홍빛)

> 사진 + 역할 + 이름 심플한 구성을 생각햇습니다
> 그리고 각 사람을 누르면 개인 페이지로 연결되어 경력사항을 볼수잇도록 할 예정입니다

`270×350` 빈 노란 박스의 내용이 확정됐고, **`/people/[id]` 개인 페이지는 유지**입니다.
기존 `PhotoField` + Supabase Storage 업로드를 그대로 재사용하면 됩니다.

### 제작 예산 — #31 (홍빛)

> 총 제작 예산 → 예산 항목 을 보여주는 느낌
> 예산 항목별 금액은 공개하지 않을 예정이라, 항목만 기입되면 충분함니다

현재 `BudgetItem`에 금액 필드가 없는 것이 의도대로입니다. 총액
(`총 예상 예산 : 9,000,000원`)만 노출합니다.

### 제작 일정 — #30 (홍빛)

> 완료된 일정과 현재 진행 중 & 예정인 일정을 나뉘어 볼 수 잇도록
> 휴대폰으로 확인햇을 때 너무 길지않도록 타임라인 일부를 보여주고
> 자세한 건 더보기로 볼 수 잇도록

시안의 `더보기` 토글이 모바일을 염두에 둔 장치였습니다.

### 정렬 문제 — #44 (dladmsgp0311, 15시간 전)

> 이거 위치 조절을 못하겠네요 .... 팀장님 확인하고 조율 해주시면 왕감사 하겟습니다

푸터 `left:-10px`을 정상값으로 고쳐 구현하기로 한 결정과 부합합니다.

### 흰색 오퍼시티 — #25 (홍빛)

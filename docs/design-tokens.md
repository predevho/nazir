## 5. 시안 자체의 정리 오류

구현 전에 디자이너 확인이 필요한 항목입니다.

1. **GNB 중앙 정렬 오프셋** — `calc(50% - 761px/2 - 16.5px)`, 16.5px 왼쪽으로 치우침.
   13개 프레임 전부 동일하게 어긋나 있어 의도일 수도 있음.
2. **푸터 `left: -10px`** — 프레임 밖으로 10px 벗어남. 전 프레임 공통.
3. **로고 `top: -7px`** — 80px 헤더 위로 삐져나옴. 의도된 오버플로인지 확인.
4. **노랑 두 값 혼용** — `#DAC32D`(스타일) vs `#CBA610`(raw).
5. **폰트 이름 3종 혼용** — `Heir of Light OTF` / `Heir of Light` / `Sandoll HeirofLight`.
6. **`대하여` 페이지네이션 도트 3개 vs 서브페이지 4개** — 04에서도 3번째 도트가 활성.
7. **line-height %/px 혼재** — `140%`와 `22px`가 같은 15px 본문에 섞여 있음.
8. **랜딩 카드 아이콘 크기 제각각** — `181×160` ~ `139×122`.
9. **모바일 시안 없음** — 1920px 고정. 브레이크포인트 규칙 미정.

## 6. 코드 반영 현황

이미 반영한 것:

- `app/globals.css` — `@font-face` 3종 (`Heir of Light` 400/700, `Griun Gossi` 400)
- `tailwind.config.ts` — `ds-*` 색상 6종, `maxWidth.content: 1398px`,
  `fontFamily.heir` / `fontFamily.griun`
- `public/fonts/` — 폰트 파일 배치 폴더 + README

- 기존 `gold` / `paper` / `velvet` → `ds-*` 마이그레이션 (화면 단위로 진행)
- GNB 5개 메뉴 + CTA 구조 변경
- `함께하는 사람들` 최상위 라우트 신설
- `응원 게시판` 기능 신규 구현 (테이블 · API · 폼)
